## 🚀 Projeto em Destaque

### IdentIFica — Sistema de Controle de Acesso Físico

Projeto acadêmico de um sistema de controle de acesso físico com **autenticação multifatores**, desenvolvido para gerenciar e registrar o acesso a ambientes, como laboratórios.

A solução integra uma **API REST em Java e Spring Boot**, banco de dados **MySQL**, um dispositivo embarcado baseado em **ESP32**, leitor RFID e métodos adicionais de autenticação. O projeto busca proporcionar maior segurança, controle de permissões e rastreabilidade dos acessos.

**Tecnologias principais:** Java, Spring Boot, MySQL, ESP32 e C/C++.
